# Валідатор дужок

Програма перевіряє правильність закривання круглих `()`, фігурних `{}` та кутових `<>` дужок за допомогою стеку на основі `list`.

## Запуск програми

```bash
python bracket_validator.py
```

## Запуск тестів

```bash
python -m unittest -v
```

## Збірка пакета

```bash
python -m pip install build
python -m build
```

Зібрані файли з'являться у папці `dist`.
